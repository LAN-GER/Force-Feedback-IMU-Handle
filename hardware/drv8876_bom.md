# DRV8876 典型应用阻容选型（本工程）

对照手册 [DRV8876](https://www.ti.com/lit/ds/symlink/drv8876.pdf) **图 18 典型应用原理图**，按本项目约束计算：

| 项目 | 取值 |
|------|------|
| 电机 | GA12-N20，**VM = 5 V** |
| MCU | ESP32-C3，逻辑 **VCC = 3.3 V** |
| ADC | 拟用 **GPIO4（ADC1_CH4）**，有效量程按 **≈0–2.5 V** 设计（`ADC_ATTEN_DB_11/12`） |
| 封装 | **DRV8876PWPR**（PWP / HTSSOP-16） |
| 控制 | 原理图同款：**PMODE=GND → PH/EN**；**IMODE=GND** |

手册常数：\(A_{IPROPI} = 1000\,\mu\mathrm{A/A}\)。

\[
V_{IPROPI} = I_{OUT}\times A_{IPROPI}\times R_{IPROPI}
= I_{OUT}\times 0.001\times R_{IPROPI}
\]

\[
I_{TRIP} = \frac{V_{VREF}}{0.001\times R_{IPROPI}}
= \frac{1000\times V_{VREF}}{R_{IPROPI}}
\quad（I_{TRIP}\text{ 单位 A，}R\text{ 单位 }\Omega）
\]

> 传感/限流电阻只与电流、ADC、\(V_{REF}\) 有关，**不随 VM 变**；VM 从 6 V→5 V 主要改变的是电机电流量级（约按电压比例缩小），从而影响「推荐档」选取。

## 2. \(R_{IPROPI}\)（电流 → ADC 电压）

设计目标：正常工作电流落在 ADC 中段，堵转不超过 \(I_{TRIP}\)/ADC 满偏。

N20 堵转电流近似 \(I_{stall}\propto V_M\)。相对 6 V 约 ×5/6：

| | @ 6 V（参考） | **@ 5 V（本设计）** |
|--|---------------|---------------------|
| 空载 | 数十～两百 mA | 略低，约数十～**150 mA** |
| 堵转（经验） | 约 0.5–1.5 A | 约 **0.4–1.25 A**（以铭牌为准） |

### 推荐方案 A（**VM=5 V 默认**）

| 参数 | 值 |
|------|-----|
| \(R_{IPROPI}\) | **2.2 kΩ**（1% 金属膜，0603/0805） |
| ADC 满偏 2.5 V 对应电流 | \(I = 2.5 / (0.001\times 2200) \approx \mathbf{1.14\,A}\) |
| 分辨率（约） | 12-bit、2.5 V → ~0.28 mA/LSB（理论） |

### 方案 B（堵转偏大 / 想留余量）

| 参数 | 值 |
|------|-----|
| \(R_{IPROPI}\) | **2.0 kΩ** |
| 2.5 V 对应 | \(I = \mathbf{1.25\,A}\) |

### 方案 C（电流更小、分辨率更高）

| 参数 | 值 |
|------|-----|
| \(R_{IPROPI}\) | **2.49 kΩ**（或 2.4 kΩ） |
| 2.5 V 对应 | \(I \approx \mathbf{1.0\,A}\) |

**建议先按方案 A（2.2 kΩ）**；实测堵转经常 >1.1 A 再改 2.0 kΩ。

固件换算（方案 A）：

\[
\hat{I} = \frac{V_{ADC}}{0.001\times 2200}
= \frac{V_{ADC}}{2.2}
\quad（I\text{ 单位 A}）
\]

## 3. \(V_{REF}\) 与 \(R_{REF1}/R_{REF2}\)（限流阈值）

IPROPI 内部相对 \(V_{REF}\) 有钳位，**建议 \(V_{REF}\approx 2.5\,\mathrm{V}\)**，与 C3 ADC 满量程对齐，同时保护 ADC。  
（\(V_{REF}\) 分压来自 3.3 V，与 VM=5 V **无关**。）

取 **方案 A**：\(R_{IPROPI}=2.2\,\mathrm{k}\Omega\)，\(V_{REF}=2.5\,\mathrm{V}\)：

\[
I_{TRIP} = \frac{1000\times 2.5}{2200} \approx \mathbf{1.14\,A}
\]

与 ADC 满偏一致。

### 分压（从 3.3 V）

\[
V_{REF} = 3.3\times\frac{R_{REF2}}{R_{REF1}+R_{REF2}}
\]

| 组合 | \(R_{REF1}\)（上） | \(R_{REF2}\)（下） | \(V_{REF}\) | \(I_{TRIP}\)（\(R_{IPROPI}=2.2\,\mathrm{k}\Omega\)） |
|------|-------------------|-------------------|-------------|------------------------------------------------------|
| **推荐** | **10 kΩ** | **33 kΩ** | \(3.3\times 33/43 \approx \mathbf{2.53\,V}\) | \(\approx\mathbf{1.15\,A}\) |
| 备选 | 7.5 kΩ | 24 kΩ | ≈2.51 V | ≈1.14 A |
| 备选 | 9.1 kΩ | 30 kΩ | ≈2.53 V | ≈1.15 A |

分压电阻用 **1%**；节点可并联 **100 nF** 到 GND（可选）。

若用方案 B（2.0 kΩ）：同样 \(V_{REF}\approx2.53\,\mathrm{V}\) → \(I_{TRIP}\approx 1.26\,\mathrm{A}\)。

## 4. \(C_{Bulk}\)（VM 大容量电容）

经验估算：\(\Delta V \approx I\cdot \Delta t / C\)。  
VM=5 V 时尖峰电流约低于 6 V：取尖峰 **0.8 A**、允许掉电 **0.3 V**、有效时间 ~50 µs → \(C \gtrsim 130\,\mu\mathrm{F}\) 偏保守。N20 常用：

| 推荐 | 说明 |
|------|------|
| **100 µF / 16 V**（铝电解或固态）+ **0.1 µF** 陶瓷 | **默认**（耐压仍建议 ≥10 V，优先 16 V） |
| 布线短、电流更小 | 可降到 **47 µF / 16 V** |
| 线长 / 电源软 | 升到 **220 µF / 16 V** |

紧贴 VM/GND；若用钽电容，优先聚合物钽且耐压 ≥16 V（见前文讨论）。

## 5. 与 MCU 的对应（对照图 18）

| 原理图 | 本工程建议 |
|--------|------------|
| Controller PWM → EN/IN1 | **GPIO2**（LEDC PWM） |
| Controller I/O → PH/IN2 | **GPIO3**（方向） |
| Controller I/O → nSLEEP | **GPIO20** |
| Controller ADC ← IPROPI | **GPIO4**（需去掉 WS2812） |
| nFAULT | 可选；接则需上拉 10 kΩ，C3 无空闲脚时可先悬空不接 |
| PMODE | **GND**（PH/EN） |
| IMODE | **GND**（与典型图一致） |
| VM | **5 V** 电机电源 |
| VCC（上拉/分压） | **3.3 V** |

> 现有固件是双 PWM（IN1/IN2）；换成 PH/EN 后软件需改为「PWM + DIR」，与典型图一致。

## 7. 校验清单

- [ ] \(R_{IPROPI}\) 一端 IPROPI、一端 GND，走线短  
- [ ] ADC 输入不超过约 2.5–3.0 V（由 \(V_{REF}\) 钳位兜底）  
- [ ] 用已知电阻负载或电流表核对：\(I_{real}\) vs \(V_{ADC}/(0.001 R_{IPROPI})\)  
- [ ] 小电流区有固定偏置（手册说明），软件做零点校准  
- [ ] 确认电源为 **5 V**（勿与 3.3 V 逻辑混用）
