# ESP32-C3FH4 引脚分配

软件 `software/components/bsp/include/bsp/bsp_pin.h` 必须与本表一致。
BMI088 MISO 使用 GPIO6；GPIO9 是 BOOT strapping，禁止连接 MISO。

## MCU ↔ BMI088（SPI Mode 3）

| ESP32-C3 GPIO | 方向 | BMI088 | 说明 |
|----------------|------|--------|------|
| GPIO8 | 出 | SCK | strapping；串 22 Ω 阻尼 |
| GPIO6 | 入 | SDO1 + SDO2 | Acc/Gyro MISO 并联；串 22 Ω；避开 GPIO9 |
| GPIO10 | 出 | SDI | MOSI；串 22 Ω |
| GPIO5 | 出 | CSB1 | 加速度计片选，空闲高；串 22 Ω |
| GPIO7 | 出 | CSB2 | 陀螺仪片选，空闲高；串 22 Ω（可与上共一排阻，见下） |

VDD / VDDIO = 3.3 V。PS 脚接 GND 选 SPI（若模块有 PS）。

### SPI 串联阻尼（推荐）

MCU 与 BMI088 之间，**SCK / MISO / MOSI / CS** 各串 **22 Ω**。可用一颗 **4×22 Ω 独立型排阻**（8 脚、四路互不共端）：

```text
MCU GPIO8  --[22]-- BMI088 SCK
MCU GPIO6  --[22]-- BMI088 SDO1+SDO2
MCU GPIO10 --[22]-- BMI088 SDI
MCU GPIO5  --[22]-- BMI088 CSB1
```

- **必须用独立型（isolated）排阻**，不要用共端（bussed）排阻，否则四路信号会短在一起。
- 双 CS 共 5 根线：4 路排阻 + **CSB2（GPIO7）另串一颗 22 Ω**；或两颗 4×22 排阻只用其中 5 路。
- CS 加串阻优先级低于 SCK；线极短时 CS 也可不加，但 22 Ω 一般无副作用。
- 8 MHz SPI 下 22 Ω 足够；电阻靠近 MCU 或靠近传感器均可。

## MCU ↔ IMU 加热（抗温漂）

环绕 BMI088 的贴片 **100 Ω** 加热电阻，由 **YJL3400A**（N-MOS，SOT-23）低侧开关。

| ESP32-C3 GPIO | 方向 | 连接 | 说明 |
|----------------|------|------|------|
| GPIO21 | 出 | YJL3400A Gate | LEDC PWM，1 kHz；高=导通加热 |

推荐接法：

```text
3V3 ----[ 100Ω 加热电阻 ]---- Drain (YJL3400A)
                              Source ---- GND
GPIO21 --[ 100Ω ]--+-- Gate
                   |
                 [10kΩ]
                   |
                  GND
```

- 3.3 V / 100 Ω ≈ **33 mA / 0.11 W**，仅作局部恒温，勿用过高电压长时间满占空比。
- 加热电阻尽量贴 IMU 封装侧壁或模块背面铜皮，与传感器热耦合。
- 栅极串联 100 Ω、对地 10 kΩ 下拉，上电默认关断。

## MCU ↔ DRV8833 + GA12-N20

### 1）MCU → DRV8833（逻辑侧）

| ESP32-C3 GPIO | 方向 | DRV8833 | 说明 |
|----------------|------|---------|------|
| GPIO2 | 出 | AIN1（或 IN1） | LEDC PWM；正转侧 |
| GPIO3 | 出 | AIN2（或 IN2） | LEDC PWM；反转侧 |
| GPIO20 | 出 | nSLEEP | 高=唤醒；低=休眠/高阻 |
| 3V3 | — | VCC（逻辑供电，若板子有） | 与 MCU 同 3.3 V |
| GND | — | GND | **必须与电机电源负极共地** |

本固件只用 **A 路 H 桥**（单轴）。若模块是双路，B 路 IN 悬空或接地即可。  
部分模块还有 `nFAULT`：可不接；若接 MCU，需上拉，低电平表示故障。

### 2）电源 → DRV8833

| 电源 | DRV8833 | 说明 |
|------|---------|------|
| 电机电源正极（典型 **6 V**，按电机额定） | **VM** | 与 3.3 V **分开**，勿用 USB 3.3 V 驱动电机 |
| 电机电源负极 / 系统地 | **GND** | 与 MCU GND 短接共地 |
| — | VM 旁路 | 靠近芯片：100 nF + ≥10 µF 电解/陶瓷 |

堵转电流可能数倍于空载，电源需有余量；初调建议限流或小占空比。

### 3）DRV8833 → N20 电机绕组（动力线）

| DRV8833 | GA12-N20（常见线色） | 说明 |
|---------|----------------------|------|
| **AOUT1**（OUT1） | 电机 **M+**（常为 **红**） | 对调红/白可反转机械正方向 |
| **AOUT2**（OUT2） | 电机 **M−**（常为 **白**） | 与软件 `enc_dir` / 正负 duty 配合 |

软件约定：`duty > 0` → IN1 出 PWM、IN2=0（电流 AOUT1→AOUT2 一侧）；反转则对调。若实机方向反了，可对调电机两根线，或设 `enc_dir=1`。

### 4）N20 霍尔编码器 → MCU（信号线，不经 DRV8833）

编码器 **独立供电**，不要接到 VM。

| GA12-N20（常见线色） | 接到 | 说明 |
|----------------------|------|------|
| 编码器 VCC（常为 **黑**） | **3.3 V** | 极性勿反；部分模块标 3.3–5 V，本工程用 3.3 V |
| 编码器 GND（常为 **蓝**） | **GND** | |
| A 相（常为 **绿** 或黄） | **GPIO0** | 可外接 4.7 kΩ→3.3 V（模块已带上拉则可省） |
| B 相（常为 **黄** 或绿） | **GPIO1** | 同上，**A/B 各一颗** |

> 淘宝/厂家线色偶有差异，以卖家线序表为准。认线口诀：**红白走电机（接 OUT），黑蓝给编码供电，绿黄是 A/B**。

### 5）总连接示意

```text
                    3V3 ----+---- DRV8833 VCC
                            +---- 编码器 VCC (黑)
                            +---- (可选) A/B 上拉 4.7k
  ESP32-C3                  |
  GPIO2 -----------------> AIN1
  GPIO3 -----------------> AIN2      DRV8833
  GPIO20 ----------------> nSLEEP
  GND ------------------- GND ------+
                                    |
  电机电源+ (6V) --------> VM       |
  电机电源- -------------- GND -----+---- 共地
                                    |
                           AOUT1 ---> 电机 M+ (红)
                           AOUT2 ---> 电机 M- (白)

  GPIO0 <---- A 相 (绿) <---- 编码器
  GPIO1 <---- B 相 (黄) <----
  GND   <---- 编码器 GND (蓝)
```

电机电源（典型 6 V）与逻辑 3.3 V 分离；编码器 VCC 用 3.3 V。
DRV8833 VM 接电机电源，GND 共地。

## MCU ↔ WS2812 / USB / 用户键

| ESP32-C3 GPIO | 连接 |
|----------------|------|
| GPIO4 | WS2812 DIN |
| GPIO18 / GPIO19 | USB D− / D+（原生 USB-Serial/JTAG） |
| GPIO9 | 用户键（与 BOOT 共用） |

### 用户键接法（GPIO9）

```text
GPIO9 --+-- 按键 ---- GND
        |
      内部上拉（可再外接 10 kΩ 到 3.3 V）
```

- 按下为低；运行中短按 = **编码器清零**（与 USB `{"cmd":"zero"}` 相同）。
- **上电 / 复位时不要按住**，否则进入下载模式。
- 禁止把传感器 MISO 接到 GPIO9。
