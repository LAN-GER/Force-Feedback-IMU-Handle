连接说明与字段说明
通过本地 HTTP 服务打开页面，在桌面 Chrome / Edge 中点击「选择串口并连接」，在浏览器自带的端口选择弹窗中选择板子的 USB 串口。首次访问需要通过该弹窗授权端口。连接后自动发送 get 和 sub，不更改电机控制参数。无数据时检查固件、USB 接口和串口占用；波特率可先用 115200。
暂停订阅只停止遥测。停机并断开会依次发送 duty=0、heater=0、unsub，再释放串口。拔线或关闭页面无法保证电机停机，请先点击停止电机。板端未提供温度、故障引脚或固件版本遥测，因此页面不会显示这些值。
CSV 记录最近 30,000 帧（50 Hz 时约 10 分钟），时间为浏览器接收时间。参数仅在收到板端回复后确认；get 超时可检查固件 USB JSON 发送缓冲大小。演示数据标记为模拟，退出演示后清除。
